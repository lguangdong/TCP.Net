## SocketTest 学习沙盒 — Lab0/LabC1 搭建完成

用户目标：以 .NET C# 客户端开发视角学习 Socket 编程。已给出两版学习路线（服务端版 + 客户端版），并按其确认落地第一批代码。

### 已创建的项目（均已 `dotnet sln add` 并编译通过，0 警告 0 错误）
- `src/SocketTest.Protocol/`（net8.0 类库）：客户端与服务端共用协议
  - `ProtocolConstants`：16 字节帧头 `magic(2,'S','K')|version(1)|msgType(1)|flags(2)|seq(4)|payloadLen(4)|reserved(2)`，大端序，MaxFrameSize=64KB
  - `Frame` / `FrameCodec`（Encode/TryParse/WriteAsync）/ `PayloadCodec`（UTF-8 JSON）
  - `FrameReader`：循环读满实现粘包拆包，EOF→null，长度校验
  - `Messages`：LoginRequest/LoginResponse/EchoPayload/TextMessage/ServerNotice
  - `MessageType`：Ping=1,Pong=2,EchoRequest=10,EchoResponse=11,LoginRequest=20,LoginResponse=21,TextMessage=30,ServerNotice=40
- `labs/Lab0_MockServer/`（AssemblyName=MockServer，可执行）：可注入故障的假服务端
  - 命令：status / drop <0-100> / delay <ms> / jitter <ms> / reset / push <text> / kill / help / quit
  - `FaultInjector` 丢包+延迟+抖动；`ClientSession` 用 SemaphoreSlim 串行写；密码 `wrong` 触发登录失败分支
- `labs/LabC1_Client/`（AssemblyName=LabC1.Client，可执行）
  - `ClientConnection`：BoundedChannel 单写者发送队列 + 读循环，ConnectAsync 带超时，Abort 供心跳踢连接
  - `RpcClient`：seq 自增 + ConcurrentDictionary<uint,TaskCompletionSource<Frame>>，超时清理、Detach 时失败所有 pending
  - `ConnectionStateMachine`：Disconnected/Connecting/Handshaking/Online/Reconnecting + 指数退避(1s→30s，带 0.5~1.0 抖动)
  - `HeartbeatMonitor`：定时 Ping、RTT 统计、连续丢失 maxMissed 次触发 Dead
  - `ChatClient`：门面，RunAsync 里 while 循环完成"连→握手→上线→等断→退避→重连"
  - `MainThreadDispatcher`：演示 IO 线程回调必须切主线程
  - 命令行：`--host --port --user --password --heartbeat <秒> --demo`；交互命令 state/echo/chat/quit

### 已解决的编译问题
- `ProtocolConstants.Magic` 原为 `ReadOnlySpan<byte>` 属性，在 async 方法里持有会触发 CS9202（C# 12 禁止 async 中的 ref struct 局部变量）→ 改为 `static readonly byte[]`
- `RpcClient` 缺 `using LabC1.Client.Connection;`
- `ConcurrentDictionary.Values` 不实现 `IReadOnlyCollection<T>` → 属性类型改为 `ICollection<T>`
